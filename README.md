PokeTeam

> Monte o seu time da sua maneira e mostre para o mundo!

PokeTeam é um fórum de times Pokémon desenvolvido como projeto individual do curso de Análise e Desenvolvimento de Sistemas da SPTech (2026). A plataforma permite que treinadores se cadastrem, montem seus times favoritos e os compartilhem com a comunidade.

---

Funcionalidades

- **Cadastro e Login** de usuários via API
- **Montagem de times** com até 6 Pokémons
- **Fórum** para visualizar times postados por outros treinadores
- **Dashboard** com dados e estatísticas da plataforma

---
